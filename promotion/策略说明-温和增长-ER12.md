# 温和增长 · ER12：实际策略与参数

**一句话**：3 倍杠杆的趋势跟随，用 1.25% 的单笔风险预算换长期复利；亏完之后加一道 ER12 门，只在行情重新走出干净方向时才允许回头。历史回测资金加权年化 39.05%，盘中回撤保守上界 23.93%。

> 站内小鱼干模拟基金计划。以下策略规则来自冻结实现，历史数字来自同一段历史回测；两者都不是收益承诺，实际基金业绩尚未验证。

---

## 一、它到底怎么交易

策略不吃行情预测，只吃**方向能不能延续**。每根**小时 K 线收盘**之后判断一次，**4 秒行情只用于报价、止损比较和结算，不产生信号**——它不是高频策略。

### 1. 入场条件（两个都满足才开仓）

- 收盘价 **>** EMA96；
- EMA96 **>** 24 小时前的 EMA96（趋势向上）。

指标口径（[hourly_signals.py:42-64](src/raricy_capital/hourly_signals.py#L42-L64)）：

| 指标 | 算法 | 参数 |
| --- | --- | --- |
| EMA96 | 前 96 根收盘均值做种子，其后 `2/97×close + 95/97×EMA` | `ema_hours=96` |
| EMA 斜率 | 当前 EMA96 与 24 小时前 EMA96 比较 | `slope_hours=24` |
| ATR14 | 前 14 根真实波幅均值做种子，其后 Wilder 平滑 `(13×ATR+TR)/14` | `atr_period=14` |
| 止损距离 | `distance = 2 × ATR / close` | `atr_stop=2.0` |
| ER12 | `(收盘 − 12小时前收盘) ÷ Σ(逐小时变化)`，取值 0–1 | 亏损门用 |

### 2. 仓位：波动越大，开得越小

仓位公式（[strategy.py:65-86](src/raricy_capital/strategy.py#L65-L86)）：

```
q      = min(cap, risk / (distance + fee × (1 − distance)))
stake  = ⌊q × 可用交易现金 / leverage⌋     # 低于站点最小份额则不开仓
```

- `q` 是**名义仓位／交易桶权益**的比例，`stake` 才是真正投入的保证金。
- `distance`（=2ATR/close）越大，`q` 越小：**震荡放大时自动缩小名义敞口**，这是这套公式的波动自适应。
- 低波动时 `distance` 很小，`cap` 会成为约束，此时单笔实际风险预算可能**小于**标称的 1.25%。

### 3. 离场：止损短、盈利单放长

- **固定止损**：`stop = entry × (1 − distance)`，即 2ATR。
- **趋势失效**：小时信号转为 `exit`（收盘价不再高于 EMA96，或 EMA 斜率转平/向下）。
- **超时**：持仓满 `max_hold_days=14` 天。
- **停机 / 日内暂停**触发时安排退出。
- **没有止盈、没有移动止盈、没有分批减仓**——盈利单只有在趋势失效、满 14 天或停机时才走。这就是它胜率低但盈亏比高的原因。

### 4. 冷却：退出后不马上回头

退出（含止损）后，先等**下一个整点**，**再**冷却 4 小时；叠加 15 秒信号新鲜度窗口，实际最早重新入场落在退出那一刻之后 4–5 小时的那个小时边界上（[strategy.py:118-129](src/raricy_capital/strategy.py#L118-L129)）。

**入场只允许在小时收盘后 15 秒内**（`ENTRY_WINDOW_MS = 15000`）——中途登录不会去追一个已经过期的信号。

**同时最多一个仓位**，不加仓、不补仓。

## 二、ER12 亏损门：这一档的名字由来

资本1 独有，也是它和激进档最核心的差别（[strategy.py:132-139](src/raricy_capital/strategy.py#L132-L139)）：

| 项目 | 规则 |
| --- | --- |
| 触发 | 上一笔已平仓交易是**亏损** |
| 窗口 | 从该笔结算时刻起 **12 小时**内 |
| 要求 | **同时**满足 `ER12 ≥ 0.30` 且过去 12 小时净价格变化 **> 0** |
| 到期 | 12 小时一过自动失效，其他趋势与风险条件照常 |

翻译成人话：**亏完之后，先停一下；只有行情重新走出连贯的方向（ER 高且净涨），才允许再入场。** 目的是避免在震荡里被反复来回打。ER12 越高表示趋势越连贯——它衡量的不是涨跌幅度，而是这段路走得干不干净。

## 三、风险闸门（三层）

日切用**北京时**（[strategy.py:41-43](src/raricy_capital/strategy.py#L41-L43)）。

| 闸门 | 阈值 | 行为 |
| --- | --- | --- |
| 日内亏损暂停 | 净值较当日起始跌 **1.5%** | 退出持仓，**当日**暂停新开仓，次日恢复 |
| 永久回撤停机 | `1 − NAV/峰值 ≥ 25%` | 进入永久停机，此后只做估值与对账，**不再开仓** |
| 单笔止损 | 2ATR | 单笔亏损被 1.25% 风险预算限制 |

两条关键设计（[trader.py:330-356](src/raricy_capital/trader.py#L330-L356)、[strategy.py:89-115](src/raricy_capital/strategy.py#L89-L115)）：

- **峰值只升不降**；
- **外部资金流不改变净值**——申购、赎回、分红等流量会把「单位数」按 `equity / (equity − flow)` 缩放，使净值只随交易盈亏变动。因此**追加本金既不能抬高净值，也不能把基金从停机线拉回来**（`set_running(True)` 在停机状态下直接抛 `permanent_halt`）。

## 四、冻结参数表

参数在 `src/raricy_capital/contracts.py` 的 `POLICIES['capital1']` 里**冻结**，配置里改不动（写了不一致的 `policies` 会直接报 `policies_are_frozen`）。

| 参数（代码字段） | 值 | 含义 |
| --- | ---: | --- |
| `leverage` | 3 | 把 stake 放大成名义仓位的倍数 |
| `risk` | 1.25% | 单笔目标亏损／交易桶权益 |
| `cap` | 2 倍 | 单笔名义仓位上限／交易桶权益 |
| `daily_loss` | 1.5% | 日内亏损暂停线 |
| `drawdown_limit` | 25% | 净值永久停机线 |
| `loss_gate_hours` | 12 | 亏损后 ER12 门窗口 |
| `cooldown_hours` | 4 | 退出后冷却（另加下一个整点） |
| `max_hold_days` | 14 | 最长持仓 |
| `ema_hours` / `slope_hours` / `atr_period` | 96 / 24 / 14 | 信号指标 |
| `atr_stop` | 2.0 | 止损 = 2ATR |

产品侧规则（对所有基金一致，见 [GUIDE.md](../docs/usage/GUIDE.md)）：申购费 5%、紧急赎回费 10%、月度可分配利润 10% 分红、每月普通赎回不超过份额 20%、申购/普通赎回限每月 1–7 日窗口。

> **注意**：`leverage=3` **不是**「权益被放大 3 倍持续暴露」。实际平均名义仓位／权益只有 **0.3061**（正常情景）——因为波动大时 `distance` 大、`q` 就小。

## 五、历史回测（2017-08-18 至 2026-10-01，不含终点）

| 指标 | 正常执行 | 费用翻倍 + 延迟 8 秒 |
| --- | ---: | ---: |
| 资金加权年化（XIRR） | **39.05%** | **32.81%** |
| 盘中回撤保守上界 | 23.93% | 24.49% |
| 4 秒收盘回撤 | 23.53% | 23.85% |
| 交易桶单位净值 CAGR | 45.82% | 39.60% |
| 交易数 / 胜率 / PF | 1015 / 26.70% / 1.5592 | 1005 / 25.77% / 1.4700 |
| 最差 30 日 | −10.56% | −11.81% |
| 永久停机 / 强平 | 无 / 0 | 无 / 0 |

**怎么读**：

- **26.7% 的胜率不是缺陷。** 亏损单被 2ATR 止损快速砍掉，盈利单没有止盈、被允许跑。正常情景 1015 笔里约 271 笔盈利、744 笔亏损，平均每笔盈利 ≈ 7862、平均每笔亏损 ≈ 1837，**赢亏比约 4.3 倍**（PF 1.5592）。只看胜率会得出与 PF 完全相反的评价。
- **停机阈值紧贴历史最深水位。** 正常 23.93%、压力 24.49%，距 25% 停机线只差 1.07 / **0.51** 个百分点。历史没有触发停机（`halt_time` 全为 `null`、`liquidations` 为 0），但跳价、报价中断、退出延迟都可能让实际回撤越线——**25% 是停机规则，不是损失封顶**。
- **约 38% 的月份是亏的**（`negative_months` 42/110），最长水下 428 天，期末仍未创新高。这不是一条每个月都赚的曲线。
- **年度会分化**：2018 年 XIRR −10.75%（唯一亏损年）、2020 年 +111.77%、2024 年 +104.36%、2025 年 +5.16%。趋势策略吃的是方向延续，**不是当年涨跌幅**。

## 六、它适合谁

- 想用**较小的风险预算**参与 BTC 趋势，更看重增长过程中的回撤控制；
- 能接受低胜率、长期持有、某些年份不赚钱甚至亏钱；
- 理解「温和」只是两条档位之间的**相对**定位——3 倍杠杆并不低风险，正常历史回撤已经贴到停机线附近；
- 明白它与激进档**都是 BTC 多头**，同时持有**不构成风险分散**。

**数据口径**：金额单位为模拟小鱼干。行情 2017-08-18 至 2026-10-01；2017-01-01 初始投入 1000，其后每月投入 1000，累计出资 117000，每笔已实现正净利润 90% 复投、10% 进留存现金。年化为资金加权年化（XIRR），回撤为盘中保守上界。压力测试仅包含手续费 0.02% 升至 0.04%、额外延迟 8 秒。历史采用逐笔利润复投，当前基金计划按月评估可分配利润的 10% 分红，**历史资金规则与当前产品规则不同，不能互相引用为业绩**。参数经同一段历史反复筛选，存在过拟合；历史结果不代表未来收益。
