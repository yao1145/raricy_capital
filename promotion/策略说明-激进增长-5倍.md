# 激进增长 · 5倍：实际策略与参数

**一句话**：同样跟随 BTC 小时趋势，但把杠杆、单笔风险预算和名义仓位上限都放到最大档；更少的约束、更高的收益弹性，也伴随更深的回撤。历史回测资金加权年化 152.54%，盘中回撤保守上界 63.82%——**需要能承受资产从高点回落超过一半**。

> 站内小鱼干模拟基金计划。以下策略规则来自冻结实现，历史数字来自同一段历史回测；两者都不是收益承诺，实际基金业绩尚未验证。

---

## 一、它到底怎么交易

与温和档**共用同一套信号与执行框架**，差别只在三个风险数字上。每根**小时 K 线收盘**后判断一次，**4 秒行情只用于报价、止损比较和结算，不产生信号**。

### 1. 入场条件（两个都满足才开仓）

- 收盘价 **>** EMA96；
- EMA96 **>** 24 小时前的 EMA96（趋势向上）。

指标口径（[hourly_signals.py:42-64](src/raricy_capital/hourly_signals.py#L42-L64)）：

| 指标 | 算法 | 参数 |
| --- | --- | --- |
| EMA96 | 前 96 根收盘均值做种子，其后 `2/97×close + 95/97×EMA` | `ema_hours=96` |
| EMA 斜率 | 当前 EMA96 与 24 小时前 EMA96 比较 | `slope_hours=24` |
| ATR14 | 前 14 根真实波幅均值做种子，其后 Wilder 平滑 `(13×ATR+TR)/14` | `atr_period=14` |
| 止损距离 | `distance = 2 × ATR / close` | `atr_stop=2.0` |

### 2. 仓位：放大三倍的下注

仓位公式（[strategy.py:65-86](src/raricy_capital/strategy.py#L65-L86)）与温和档完全相同：

```
q      = min(cap, risk / (distance + fee × (1 − distance)))
stake  = ⌊q × 可用交易现金 / leverage⌋     # 低于站点最小份额则不开仓
```

但三处数字被放大：

| 概念 | 代码字段 | 温和档 | **激进档** |
| --- | --- | ---: | ---: |
| 杠杆 | `leverage` | 3 | **5** |
| 单笔风险预算／权益 | `risk` | 1.25% | **5%** |
| 名义仓位上限／权益 | `cap` | 2 倍 | **5 倍** |

波动自适应机制照旧：`distance` 越大 `q` 越小。但因为上限和预算都高得多，**实际平均名义仓位／权益达到 1.1272**（温和档只有 0.3061）——大约是温和档的 3.7 倍。

### 3. 离场：止损短、盈利单放长

- **固定止损**：`stop = entry × (1 − distance)`，即 2ATR；
- **趋势失效**：小时信号转为 `exit`；
- **超时**：持仓满 `max_hold_days=14` 天；
- **停机 / 日内暂停**触发时安排退出；
- **没有止盈、没有移动止盈、没有分批减仓**。

### 4. 冷却与会话限制

退出（含止损）后先等**下一个整点**、**再**冷却 4 小时（[strategy.py:118-129](src/raricy_capital/strategy.py#L118-L129)）；入场只允许在小时收盘后 **15 秒**内；**同时最多一个仓位**，不加仓、不补仓。

## 二、与温和档最大的差别：没有 ER12 亏损门

温和档在亏损后有一道「12 小时内要求 ER12≥0.30 且净涨」的门，**激进档没有**——`loss_gate_hours=0`，`loss_gate_allows` 立即返回 `True`（[strategy.py:132-139](src/raricy_capital/strategy.py#L132-L139)）。研究计划记录里它的 `gate` 字段也是 `baseline`。

也就是说，激进档亏损后**只有 4 小时冷却**，之后只要趋势条件重新满足就能立刻再入场，不做额外的「方向是否干净」确认。这换来了更高的入场频率，也意味着**震荡期更容易被连续打脸**。

---

## 三、风险闸门（阈值同样放大）

日切用**北京时**。

| 闸门 | 温和档 | **激进档** | 行为 |
| --- | ---: | ---: | --- |
| 日内亏损暂停 | 1.5% | **5%** | 退出持仓，当日暂停新开仓，次日恢复 |
| 永久回撤停机 | 25% | **70%** | 进入永久停机，此后只估值与对账，不再开仓 |
| 单笔止损 | 2ATR | 2ATR | 单笔亏损由 5% 风险预算限制 |

同样有两条设计约束（[trader.py:330-356](src/raricy_capital/trader.py#L330-L356)、[strategy.py:89-115](src/raricy_capital/strategy.py#L89-L115)）：

- **峰值只升不降**；
- **外部资金流不改变净值**——申购、赎回、分红按 `equity / (equity − flow)` 缩放单位数，净值只随交易盈亏变动。**追加本金不能抬高净值，也不能解除停机**。

**70% 停机线意味着什么**：它允许净值从峰值腰斩之后再跌一截。历史正常情景最深 63.82%、压力 66.71%，距 70% 只剩 6.18 / 3.29 个百分点。这不是一条「跌到 70% 才刚开始疼」的线——**大部分痛苦在到达 70% 之前就已经发生了**。

## 四、冻结参数表

参数在 `src/raricy_capital/contracts.py` 的 `POLICIES['capital2']` 里**冻结**，配置改不动。

| 参数（代码字段） | 值 | 含义 |
| --- | ---: | --- |
| `leverage` | 5 | 把 stake 放大成名义仓位的倍数 |
| `risk` | 5% | 单笔目标亏损／交易桶权益 |
| `cap` | 5 倍 | 单笔名义仓位上限／交易桶权益 |
| `daily_loss` | 5% | 日内亏损暂停线 |
| `drawdown_limit` | 70% | 净值永久停机线 |
| `loss_gate_hours` | 0 | **无 ER12 亏损门** |
| `cooldown_hours` | 4 | 退出后冷却（另加下一个整点） |
| `max_hold_days` | 14 | 最长持仓 |
| `ema_hours` / `slope_hours` / `atr_period` | 96 / 24 / 14 | 信号指标 |
| `atr_stop` | 2.0 | 止损 = 2ATR |

产品侧规则（对所有基金一致，见 [GUIDE.md](../docs/usage/GUIDE.md)）：申购费 5%、紧急赎回费 10%、月度可分配利润 10% 分红、每月普通赎回不超过份额 20%、申购/普通赎回限每月 1–7 日窗口。

## 五、历史回测（2017-08-18 至 2026-10-01，不含终点）

| 指标 | 正常执行 | 费用翻倍 + 延迟 8 秒 |
| --- | ---: | ---: |
| 资金加权年化（XIRR） | **152.54%** | **113.16%** |
| 盘中回撤保守上界 | **63.82%** | **66.71%** |
| 4 秒收盘回撤 | 63.80% | 66.70% |
| 期末总资产（模拟） | 112,600,490.54 | 26,193,229.19 |
| 交易数 / 胜率 / PF | 1100 / 26.82% / 1.3742 | 1109 / 26.06% / 1.2927 |
| 平均名义仓位／权益 | 1.1272 | 1.1160 |
| 最差 30 日 | **−35.10%** | **−35.75%** |
| 日暂停次数 | 550 | 561 |
| 永久停机 / 强平 | 无 / 0 | 无 / 0 |

**怎么读**：

- **收益高，是因为敞口大，不是因为更聪明。** 同样的信号、同样的止损，名义仓位放大约 3.7 倍，收益和回撤同步放大。这**不是**「更优策略」。
- **回撤深度是温和档的三倍以上**：63.82% vs 23.93%。最差 30 日 −35.10%，也远超温和档的 −10.56%。
- **年度会亏，而且亏得深**：2018 年 XIRR −39.75%、回撤 50.45%；2025 年 XIRR −24.40%、回撤 49.72%。牛市年份则极强（2020 年 +990.21%）。
- **巨大的模拟期末资产不是「现在的规模」**：112,600,490 小鱼干是「1000 起投、每月 1000、连续 9 年、在模拟环境里按上述规则运行」的终值，**没有**验证过在这类名义仓位下的站点容量、成交与强平能力。
- **停机线不是下跌封顶**：历史最深 66.71% 距 70% 仅 3.29 个百分点，跳价、报价中断、退出延迟都可能让它越线。

## 六、它适合谁

- 追求**更高的收益弹性**，愿意为它承担资产腰斩级别的回撤；
- 能接受某些年份亏损 25%–40%，且**不会在深水区赎回**；
- 理解 5 倍杠杆是**上限**不是持续暴露，但实际平均名义仓位／权益仍达 1.13；
- 明白它与温和档**都是 BTC 多头**，相关性高，同时持有**不构成风险分散**。

**如果你需要看到「资产从高点回落超过一半」这个数字仍然拿得住，再考虑这一档。**

---

**数据口径**：金额单位为模拟小鱼干。行情 2017-08-18 至 2026-10-01；2017-01-01 初始投入 1000，其后每月投入 1000，累计出资 117000，每笔已实现正净利润 90% 复投、10% 进留存现金。年化为资金加权年化（XIRR），回撤为盘中保守上界。压力测试仅包含手续费 0.02% 升至 0.04%、额外延迟 8 秒。历史采用逐笔利润复投，当前基金计划按月评估可分配利润的 10% 分红，**历史资金规则与当前产品规则不同，不能互相引用为业绩**。激进档在研究中只保留正常与组合压力两个情景，没有单独的「仅费用翻倍」「仅延迟」行。参数经同一段历史反复筛选，存在过拟合；历史结果不代表未来收益。
