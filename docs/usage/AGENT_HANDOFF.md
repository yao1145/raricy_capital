## 2. 项目做什么

Raricy 站内 capital1 / capital2 两只小鱼干基金服务：账户登录、申购到账、份额发行、净值、分红、普通/紧急赎回、资金收付、交易、审计、备份和管理页面。

| 位置 | 内容 |
| --- | --- |
| `src/raricy_capital/` | 实际服务；核心是 contracts、ledger、store、payments、trader、runtime、web |
| `tests/` | 服务针对性测试与四个 research 测试文件 |
| `tools/btc_*.py` | 2026-10-07 新离线量化研究；不启动基金服务 |
| `packaging/funds/` | 示例配置与部署物料 |
| `docs/design/`、`docs/usage/`、`docs/funds/` | 现行设计、使用说明、基金规则和早期研究介绍 |
| `docs/materials/research/` | 可追溯研究报告、CSV、JSON、NPY、图表与哈希清单 |
| `promotion/` | 用户要求单独存放的推广 Markdown 与配图 |
| `data/`、`.build/` | Git 忽略的运行数据与中间文件；整理时保留 |

金额用整数 1e-4 单位，份额用整数 1e-8 原子，净值用 Decimal。外部操作先持久化意图，未知结果先对账，单写者锁保护 SQLite。离线回测的浮点数组不能用作生产账簿。
