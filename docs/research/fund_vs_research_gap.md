# 历史研究口径 vs v0.3 基金口径

本文回答一个问题：**`evidence.json` 里的数字，能不能直接说成「基金业绩」？**
答案是**不能**。下面是两套口径的逐项对照、缺口的清单，以及必须在对外材料里避免的引用方式。

---

## 1. 两套资金规则对照

| 项目 | 历史研究（`evidence.json`） | v0.3 基金（[GUIDE.md](../GUIDE.md) / [FUND_PLAN_V0.3.md](../FUND_PLAN_V0.3.md)） |
| --- | --- | --- |
| 出资 | 2017-01-01 初始 1000，其后每月 1000，累计 117000 | 成立规模待定；持有人按申购窗口自行出资，**无自动月投** |
| 利润分配 | **每笔**已实现正净利润 10% 进留存现金桶、90% 留交易桶 | **月末**对可分配利润的 **10%** 分红，其余留在基金 |
| 申购费 | **无** | 净本金额外 **5%**，归机构，不进基金 |
| 紧急赎回费 | **无** | 确认总额 **10%**，归**原基金**，不计入可分配利润 |
| 份额台账 | 无（没有份额概念） | 有：份额（1e-8 原子）、除息净值、分红负债 |
| 分红基准 H / 利润池 R | 无 | 有，见 [GUIDE.md](../GUIDE.md) §7.2 |
| 月度赎回上限 | 无 | 旧份额的 **20%**，超额按比例顺延 |
| 现金利息 | **无**（`no_interest = true`） | 无 |
| 资金费率 / 借贷利息 | **无** | 未模拟，也未在实现中单独计提 |
| 单位 | 小鱼干（模拟） | 小鱼干（模拟） |

**一句话**：历史研究模拟的是「**一个账户按策略交易 + 每笔盈利 10% 存现金**」，
v0.3 模拟的是「**一个基金按策略交易 + 收 5% 申购费 + 月度分红 10% + 负债台账 + 申赎窗口**」。
两套规则的现金流、可分利润与净值路径都不同，**不能互相代入**。

---

## 2. 历史数字里没有的东西

以下五项在 v0.3 里真实存在，历史研究**从未模拟**：

1. **5% 外部申购服务费。** 净认购 1000 需支付 1050；含费总预算 1000 只有约 952.38 进基金、
   约 47.62 归机构。服务费不进基金净资产、不进利润池、不获份额——**历史数字里没有这项支出**，
   也没有对应的机构收入。每次追加都重新产生一次 5%，不是一次性费用。
2. **赎回与分红的负债项。** v0.3 里已宣告未支付的分红、已确认未支付的赎回款都是**基金应付款**，
   支付时只清负债、不二次扣净值。历史研究没有份额、没有负债、没有除息净值。
3. **基金单位净值。** 历史只有「交易桶资产 / 留存现金桶 / 总资产」三个金额。
   v0.3 的基金单位净值 = 基金净资产 ÷ 在外份额，且**同时包含两个资金桶**。
   历史交易桶回撤**不能**直接替代基金整体回撤（计划草案 §3 明确要求两者分列披露）。
4. **月度申赎窗口与 20% 赎回上限**带来的流动性约束：待付款资金不再算作开仓保证金，
   必要时需要有序减仓。历史研究里资金只进不出（除策略亏损外），**没有赎回压力**。
5. **紧急赎回费留存造成的费后净值抬升**，以及相应的 H 调整。历史留存桶是「每笔盈利 10%」，
   与紧急费无关。

## 3. 到现在为止没有跑过的东西

- **没有**按 v0.3 规则（月度可分配利润 10% 分红 + 份额台账 + 分红负债 + 5% 申购费 +
  20% 月度赎回上限 + 10% 紧急费）重算过历史。因此：
  - 不存在任何「基金单位净值」历史序列；
  - 不存在任何「分红后复利」的历史结果；
  - 不存在任何「含 5% 费用后的投资人实际回报」的历史结果；
  - 不存在任何「按 v0.3 规则重跑五年」的月度基金回测。
- **没有**把机构自有份额、其他持有人份额、费用收入三项分开的历史口径。
- 计划草案已提示：「其资金配置、分红、真实申赎、基金方共同出资及收费，
  尚未被原历史回测完整模拟。既有结果属于策略研究证据，不是该基金产品设计的已验证收益。」

## 4. 引用红线

| 不要这样写 | 原因 | 应该写成 |
| --- | --- | --- |
| 「基金历史净利润 112483490.54」 | 那是策略研究口径、含历史留存桶，且没有 5% 费用与分红规则 | 「G12/H570 历史研究口径下的模拟净利润」 |
| 「基金年化 45.82%」 | 那是剔除流量的单位净值 CAGR，且不是基金净值 | 「交易桶单位净值 CAGR（研究口径）」 |
| 「历史回撤 24.49%，最大亏 24.49%」 | 那是**盘中保守上界**，不是损失上限，也不是基金整体回撤 | 「交易桶单位净值盘中回撤上界（研究口径）」 |
| 「初始 1000 滚到 1.126 亿 = 年化 X%」 | 出资按月进入，用总资产开方不是任何收益率；也不属于基金募集规模 | 引用 JSON 现成的 `money_weighted_return_pct` |
| 「分红每月 10%」 | 历史是**每笔**盈利 10% 留存，v0.3 是**月度可分配利润** 10% 分红 | 分开表述，并注明两套规则未互相模拟 |
| 「每月投 1000 是基金规则」 | 那是回测资金口径；系统不会自动扣款 | 「历史研究的资金口径，不是持有人的缴款义务」 |

**投资人应按实际支付的含费资金计算回报**：5% 申购费意味着在净值不变的简化条件下，
普通赎回相对总支出 1050 损失约 4.76%；紧急赎回损失约 14.29%；
紧急退出要覆盖全部含费支出，份额价值需增长约 16.67%（1050 ÷ 0.90 = 1166.67）。
这些是**费用对投资人的影响**，与策略收益无关，也不能从历史数字里推出来。

## 5. 口径统一记录与剩余待核对项

1. **H570 正常情景的净利润现已统一为一套数字。**
   - `evidence.json.capital2`（来源 `btc_highrisk_funds_2026-10-03_final_r90`）：**112483490.5353**；
   - [FUND_PLAN_V0.3.md](../FUND_PLAN_V0.3.md) 附录（同样标注 `_final_r90`）：**112483490.54**。
   两者一致。早先 `_v2` 研究包的 89532345.5888 已作废。
   对外材料引用时仍应写明「历史研究口径」，并说明它不含 v0.3 的费用与分红规则。
2. **融资 / 借贷成本未计入。** 5 倍杠杆运行 9 年的借贷利息在任何情景里都没有扣。
   若将来要计入，历史数字需要重跑，不能用现有结果线性外推。
3. **站点容量未验证。** 1.126 亿小鱼干的名义仓位在模拟器里可以撮合，
   不代表真实站点能承受同等规模的成交与强平。
4. **`price` 是多少？** 历史行情来自 Binance 的 BTCUSDT 1 秒数据；
   站点练手盘的报价与成交规则是否与之一致，未在历史研究里验证，
   只在实现里以「快照 `feeRate` / `leverageOptions` / `minStake` 必须与冻结值一致」
   的闸门来防漂移。

## 6. 结论

- 历史证据的**有效用途**：说明策略形态（趋势跟随、低胜率高盈亏比、回撤特征、
  压力下的敏感方向）、说明参数选择过程存在、支撑「风险预算 / 停机线」的取值讨论。
- 历史证据的**无效用途**：预测基金净值、预测分红、预测投资人实际回报、
  宣称容量或未来收益、替代 v0.3 的基金级回测。
- 需要基金级数字时，**必须先补做**按 v0.3 规则的月度分红回测（份额台账、负债、
  5% 申购费、20% 赎回上限、紧急费）——目前**没有**这个结果。
