## 本轮内容

- 浅色运营总览、双色基金卡片、折叠账务明细、小屏布局。
- 修复登录后登录框仍显示：所有 `hidden` 元素统一隐藏。
- 登录后每 5 秒刷新，保留表单输入与展开状态；退出后隐藏运营数据。
- 显示账号恢复、结算积压和网络检测状态；无净值数据时显示空状态。

本轮只修改 `src/raricy_capital/static/` 的三个文件。未认领款功能仍为待审阅方案，见 [人工核对设计](../../design/UNCLAIMED_REVIEW.md)。

## 服务器替换方式

更新包位于本机 `.build/ui-refresh-20261004.zip`，只含 `static/index.html`、`static/style.css`、`static/app.js` 和校验清单。待 SSH 可用后：

1. 从实际 systemd 服务的 `ExecStart` 确定正在使用的 Python 环境与源码目录。不要根据工作目录猜测安装位置。
2. 用该 Python 环境查询 `raricy_capital.__file__`，目标为对应包下的 `static` 目录；备份该目录的三个原文件。
3. 在临时目录解压并核对 `SHA256SUMS`。只替换这三个静态文件，保留目标文件所有权与权限。不要覆盖配置、账簿、令牌、凭据或策略文件。
4. 三文件写入完成后刷新控制台，核对登录、退出、基金状态、净值记录与移动端布局。静态文件按请求读取，本次不需要重启基金服务。
5. 若异常，恢复备份的三个文件并刷新页面。浏览器采用旧静态资源期间不要执行管理操作。
